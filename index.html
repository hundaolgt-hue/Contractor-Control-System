Questions

Good to know

Do I need to enable macros?

No. Everything runs on standard formulas — there are no macros or add-ins. If Excel opens the file in Protected View, just click Enable Editing.ማክሮ አያስፈልግም። «Enable Editing» ን ብቻ ይጫኑ።

Which software does it work with?

Microsoft Excel 2010 or newer on Windows or Mac, Excel 365, Google Sheets, LibreOffice and WPS. In Google Sheets, links, formulas, colours and drop-downs all work; data bars and icons are not shown.

Is it in Amharic?

Yes. Choose English or Amharic in Setup and every printed document follows. The tutorial is written in both languages.አዎ — ሁሉም ሰነዶች በአማርኛ ወይም በእንግሊዝኛ ይታተማሉ።

My project is small. Is this too much?

Use the Starter workbook: BOQ, IPC, payments, cash flow, site diary and dashboard only. The other sheets still calculate but are hidden.

Can I use it on more than one project?

Yes. Make a copy of the Blank workbook for each project, then paste each project's dashboard line into the Portfolio workbook to see them all on one page.
